## Glossary

| Term | Meaning in this project |
| --- | --- |
| **Modbus** | Serial communication protocol used to read registers and coils from industrial devices. |
| **Modbus RTU** | Binary Modbus format over RS-485, used by this firmware. |
| **RS-485** | Differential serial bus standard; the firmware uses it with a MAX485 transceiver. |
| **MAX485 / DE / RE** | RS-485 transceiver and its driver/receiver enable pins, both driven by GPIO 26. |
| **ADS1115** | 16-bit I2C ADC used for 4-20 mA and 0-10 V analog inputs. |
| **ADC** | Analog-to-digital converter. |
| **4-20 mA** | Industrial current-loop analog input; readings are converted from mV to mA. |
| **FFat** | FAT filesystem library for ESP32, stored in a dedicated flash partition. |
| **FAT** | The filesystem format used by FFat. |
| **Preferences / NVS** | ESP32 non-volatile storage (`Preferences` library) used here for `auto_ota` and `company_name`. |
| **OTA** | Over-the-air firmware update. |
| **MD5** | Hash algorithm used here for firmware corruption detection, not for authentication. |
| **NTP** | Network Time Protocol; used to synchronize the real-time clock. |
| **RTC** | Real-time clock; external MCP7940 and internal ESP32Time (`rtc1`). |
| **MCP7940** | External I2C real-time clock with battery backup. |
| **AP / STA** | Access Point and Station modes of the ESP32 Wi-Fi radio. |
| **SoftAP** | Software access point; the ESP32 hosts its own Wi-Fi network. |
| **DHCP** | Automatic IP address assignment; supported on both Wi-Fi STA and Ethernet. |
| **ENC28J60** | SPI Ethernet controller used for wired network access. |
| **SPI** | Serial Peripheral Interface; used for Ethernet (SCK 14, MISO 12, MOSI 13, CS 32). |
| **I2C** | Inter-integrated circuit bus; used for ADS1115 and MCP7940. |
| **UART** | Universal asynchronous receiver-transmitter; used for RS-485 (UART1) and GSM modem (UART2). |
| **APN** | Access Point Name; cellular data profile name (default "Airtel" / `airtelgprs.com`). |
| **AT commands** | Text commands sent to the cellular modem to control network, HTTP, MQTT, and FTPS. |
| **SIM7672S / A7672S** | 4G LTE modem module family used for cellular connectivity. |
| **FTPS** | FTP over SSL/TLS; used on the GSM path with AT+CFTPS commands. |
| **MQTT** | Lightweight publish/subscribe messaging protocol. |
| **Broker** | The MQTT server that receives uplink messages. |
| **QoS** | Quality of Service; the GSM MQTT path uses QoS 1. |
| **Client ID** | MQTT client identifier; derived from MAC or company name. |
| **mTLS** | Mutual TLS; optional client-certificate authentication for HTTPS on Wi-Fi. |
| **PEM** | Base64-encoded certificate/key file format stored on FFat. |
| **FreeRTOS** | Real-time operating system underlying the ESP32 Arduino core. |
| **Task watchdog (TWDT)** | Hardware timer that reboots the system if a registered task does not reset it in time. |
| **Core pinning** | Assigning a FreeRTOS task to a specific CPU core (this firmware pins web to core 1 and backend to core 0). |
| **JSON** | Data format used for config files, payloads, and backup files. |
| **Config mode** | A 30-second window after web activity during which the backend pauses acquisition and transport. |
| **Backup file** | `/backup_file.json`; stores unsent payloads for later FTP upload. |
| **Device folder name** | Folder or filename prefix used for FTP and OTA; derived from `company_name` or MAC without colons. |
